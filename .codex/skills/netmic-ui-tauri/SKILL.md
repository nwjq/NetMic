# NetMic GUI/UX + Tauri 交互规范

## 适用场景
- 设计或改造 GUI 页面与交互
- 新增配置项、状态指标、日志页面
- 实现/调整 Tauri command、事件流与状态管理

## 信息架构（MVP）
- 模式切换：Client / Server  
- 配置页：参数 + 默认值 + 回退提示  
- 状态页：连接、延迟、丢包、缓冲深度  
- 日志页：可导出、可过滤

## 视觉规范
- 字体：选 1–2 套有辨识度的字体，避免系统默认  
- 色彩：中性基调 + 明确状态色（成功/警告/错误）  
- 背景：使用渐变或细微纹理，避免纯白平铺  
- 层级：关键状态突出，次要配置收敛

## 交互规范
- 参数输入即时校验，错误提示具体  
- 一键恢复默认值  
- Streaming 过程中禁用不可变参数  
- 断线与错误必须有清晰提示

## Tauri 交互原则
- **命令接口**：`start/stop/status` 为最小必备命令  
- **状态管理**：使用全局 `State` 保存连接与配置  
- **事件流**：指标通过事件推送 UI，避免高频轮询  
- **安全**：仅开放必要的 `allowlist` 权限

## 动效与反馈
- 页面进入使用轻量过渡  
- 指标区刷新有节奏感，避免闪烁
