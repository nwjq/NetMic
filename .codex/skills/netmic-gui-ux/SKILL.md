# NetMic GUI/UX 设计规范

## 适用场景
- 设计或改造 GUI 页面与交互
- 新增配置项、状态指标、日志页面

## 信息架构（MVP）
- 模式切换：Client / Server  
- 配置页：参数 + 默认值 + 回退提示  
- 状态页：连接、延迟、丢包、缓冲深度  
- 日志页：可导出、可过滤

## 视觉规范
- **字体**：选 1–2 套有辨识度的字体，避免系统默认  
- **色彩**：中性基调 + 明确的状态色（成功/警告/错误）  
- **背景**：使用渐变或细微纹理，避免纯白平铺  
- **层级**：关键状态突出，次要配置收敛

## 交互规范
- 参数输入即时校验，错误提示具体  
- 一键恢复默认值  
- Streaming 过程中禁用不可变参数  
- 断线与错误必须有清晰可理解的提示

## 动效与反馈
- 页面进入使用轻量过渡  
- 指标区支持节奏感刷新（非闪烁）
